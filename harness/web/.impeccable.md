# harness/web — Design Context

## Users

A **solo developer in a late-night home workshop**, alone with the bus. The harness is their single-tenant console. They are tinkering on the modular workers, reading transcripts, watching agents do work. There is no team, no audience, no demo — just one operator and a quiet machine.

The job-to-be-done: address an agent, observe the loop, intervene when needed (approvals, tool calls, cancels), and leave with the bus in a known state.

## Brand Personality

**warm · editorial · opinionated**

This is not a dashboard. It is a printed periodical for one reader. The typography is hand-set; the margins are generous; the language is unapologetic. The console has a point of view about how the bus should be operated and the UI reflects that.

Think: museum-exhibit caption, hand-set printer's apprentice manual, a magazine masthead from a small literary press. Not: SaaS app, IDE plugin, admin panel.

## Aesthetic Direction

**Theme: light (warm paper).** OKLCH neutrals tinted toward sienna (`--hue: 50`, chroma `0.005-0.012`). Pure white and pure black are forbidden — every surface has hue.

**Type pairing.** Bricolage Grotesque (display, italic for editorial weight) + Hanken Grotesk (body) + Martian Mono (eyebrows, metadata, button micro-text). No Inter, no DM Sans, no Fraunces — those are the trained reflex defaults and would flatten the voice.

**Anti-references.**
- Generic SaaS dashboards (cards, gradients, drop shadows, side-stripe borders).
- Terminal-themed dev consoles (Space Mono everywhere, neon accents, dark by default).
- Cookie-cutter "agent UIs" (oversized hero metrics, vibrant CTAs, AI-cyan accents).

**Micro-affordances.**
- Eyebrow + display title + body + footnote-after-rule for empty/intro states (colophon pattern).
- Footer is a metadata strip, not navigation.
- Buttons are small-caps with mono and a glyph mark; never bright "primary" rectangles.
- Pills are 1px tinted, not filled.

## Design Principles

1. **One reader, one bus.** Every surface assumes a solo operator. No collaboration affordances, no notifications, no gamification.

2. **Editorial weight over UI affordance.** A well-set heading does the work that an icon-and-label combo would do in a generic admin panel. Reach for typography first.

3. **Marginalia, not chrome.** Metadata lives in monospace eyebrows and footnotes — never in heavy headers or chrome.

4. **Honest copy.** Tell the operator what the bus is doing in plain prose. No "Awesome!" "Sweet!" emojis or marketing-tone microcopy. No hedging disclaimers either — be specific and stop talking.

5. **Quiet by default, loud when it matters.** The accent color (sienna) appears rarely — at the credential pill dot, the active tab underline, the eyebrow marker. The chat surface itself is mostly ink-on-paper.
