# shadcn/ui components (Base UI)

Generated by the shadcn CLI, Base UI flavour (`components.json`: style
`base-nova`, base colour neutral, Lucide icons). Add a component from
`ade/web`:

```sh
npx shadcn@latest add <name> -y
npx biome check --write src/components/shadcn
```

- Files land here, not in `components/ui`: the CLI writes lowercase names
  (`button.tsx`) and the console's own `Button.tsx` lives next door on a
  case-insensitive filesystem.
- The semantic variables these components read (`--background`,
  `--popover`, `--ring`, …) are mapped onto the console's tokens at the end
  of `src/index.css`, so they follow `data-theme` and the neutral palette
  with no `.dark` class and no second palette.
- The console keeps its own fonts and radius scale; shadcn's `--font-sans`
  and `--radius-*` remaps are deliberately not applied.
- Sections migrate one at a time: new UI reaches for these, existing
  Radix-based `components/ui` primitives stay until their section is
  redesigned.
